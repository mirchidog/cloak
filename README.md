<h2>Overview</h2>
Brave browser has a popup for listing site specific settings and statistics from one click, and now back on Chrome, the permissions menu (and especially the one for
specific websites) is hidden away within the chrome://settings directory.
Cloak is my first extension, made to provide a custom permissions menu for each site, all from one click.<br>
<ul><br>
  <li>The top of the page shows the URL's origin, and any page that starts with this will be affected.</li><br>

<h2>Installation</h2>
<ol>
  <li>Go to the site chrome://extensions.</li>
  <li>In the top right corner enable "Developer Mode".</li>
  <li>Select "Load Unpacked" and import this project's folder.</li>
  <li>On any page, click on the Cloak icon in the extensions menu to adjust the site's permissions.</li>
</ol>
